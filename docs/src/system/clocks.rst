.. title:: clocks

************************************************
:entity:`clocks` (*clocks.vhd*): Clocking system
************************************************


The SYSTEM/CLOCKS module takes the 125 MHz reference clock coming from the MGT (and also used for the SFP+ interface) and generates the following clocks:

- 125 MHz Command clock
- 50 MHz SYSMON clock (was 62.5 MHz: at 3.2 GSPS that is 51.2 samples, and 5 cycles = 256 samples made a 12.5 MHz comb in the RF-ADC spectra)
- 200 MHz for auxiliary systems (IRIG-B decoder etc.) and to be used as a clock if there is no ADC Mezzanine
- 250 MHz clock (not used)

A MMCM takes the 200 MHz word clock from one ADC (ADC0, bus A on Mezzanine A) and generates an 8-phase 200 MHz clock to feed all 16 channelizers.

Parameters
==========

- **PLATFORM_TYPE:** Target platform, defined as ``platform_type_enum`` in :ref:`chfpga-package`. Determines which MMCM primitive variant is instantiated (``MMCME2_ADV`` on Kintex-7, ``MMCME4_ADV`` on UltraScale+).
- **CLOCK_SOURCE:** Input clock that feeds the system MMCM. Valid values: ``SYSCLK`` (differential LVDS pad ``sysclk_p/n``), ``SYSCLK_BUFG`` (pre-buffered clock), ``SFP_REFCLK`` (GTX/MGT reference clock ``sfp_refclk_p/n``), ``CLK10_BUFG`` (10 MHz BUFG clock).
- **CLOCK_FREQ:** Frequency of the selected clock source in MHz. Used to compute the MMCM multiplication factors to reach a 1 GHz VCO.
- **CHAN_CLK_SOURCE:** Source for the 8-phase channelizer MMCM. ``MMCM`` generates an 8-phase clock from ``clk200``; ``ADC`` passes ``adc_clk`` directly to all channel clock outputs.
- **CHAN_CLK_FREQ:** Channelizer clock output frequency in MHz. Used to compute the channelizer MMCM dividers.
- **CHAN_RESET_DELAY:** Number of ``clk200`` cycles after the sequence reset assertion before the channelizer reset is released.
- **CORR_RESET_DELAY:** Number of ``clk200`` cycles after the sequence reset assertion before the correlator reset is released.

Interface
=========

Clock inputs
------------

- ``sysclk_p/n``: Differential LVDS clock input. Used when ``CLOCK_SOURCE = SYSCLK``.
- ``sysclk_bufg``: Single-ended BUFG-buffered clock input. Used when ``CLOCK_SOURCE = SYSCLK_BUFG``.
- ``sfp_refclk_p/n``: GTX/MGT reference clock differential input. Used when ``CLOCK_SOURCE = SFP_REFCLK``.
- ``clk10_bufg``: 10 MHz BUFG-buffered clock. Used when ``CLOCK_SOURCE = CLK10_BUFG``.
- ``adc_clk``: ADC word clock input. Used as the channelizer clock source when ``CHAN_CLK_SOURCE = ADC`` or as the alternate input to the channelizer MMCM.

Clock outputs
-------------

- ``clk200``: 200 MHz system clock generated by the system MMCM.
- ``clk125``: 125 MHz control/command system clock.
- ``corr_clk``: 250 MHz correlator clock.
- ``sysmon_clk``: 50 MHz clock for the SYSMON hardware block (gated by ``sysmon_clk_enable``).
- ``sfp_refclk_nobuf``: Unbuffered SFP/GTX reference clock passed directly to the GTX CPLL/QPLL.
- ``sfp_refclk_buf``: BUFG-buffered SFP reference clock used for the MMCM and SGMII reset logic.
- ``chan_clk``: 8-element vector of channelizer clocks, each 45° phase-shifted relative to the previous.

Channelizer clock control
--------------------------

- ``chan_clk_src_sel``: Selects the channelizer MMCM input: ``0`` = ``clk200``, ``1`` = ``adc_clk``.
- ``chan_pll_reset_in``: Resets the channelizer MMCM. Must be asserted when switching ``chan_clk_src_sel``.
- ``chan_reset_in``: Asynchronous channelizer reset input propagated (with sequencing) to ``chan_reset_out``.
- ``chan_reset_out``: Reset outputs, one per channelizer clock, synchronous to the respective ``chan_clk``.

Reset signals
-------------

- ``rst_in``: Active-high asynchronous master reset input.
- ``clk125_reset_out``: Reset synchronous to ``clk125``, held until the system MMCM is locked.
- ``clk200_reset_out``: Reset synchronous to ``clk200``, held until the system MMCM is locked.
- ``sysmon_reset_out``: Reset synchronous to ``sysmon_clk``, held until the system MMCM is locked.
- ``corr_reset_in``: Asynchronous correlator reset input.
- ``corr_reset_out``: Correlator reset synchronous to ``corr_clk``, incorporating the reset sequencer.
- ``sequence_reset_in``: Asynchronous input that triggers the full channelizer/correlator reset sequence.

Implementation details
======================

Clocking
--------

A single system MMCM generates 200 MHz, 125 MHz, 250 MHz, and ~62.5 MHz clocks from the selected input, targeting a 1 GHz VCO to minimize output jitter. When ``CHAN_CLK_SOURCE = MMCM``, a second 8-output MMCM generates the eight 45°-spaced channelizer clocks. The ``SFP_REFCLK`` input path instantiates an ``IBUFDS_GTE2`` (Kintex-7) or ``IBUFDS`` (UltraScale+/ZCU111/CRS) and a BUFG to bring the clock into the fabric MMCM.

Reset sequencer
---------------

The sequencer ensures channelizer and correlator resets are released in the correct order after all PLLs are locked. It is triggered by ``sequence_reset_in``, any master reset, or loss of MMCM lock. Running on ``clk200``, it releases the channelizer reset after ``CHAN_RESET_DELAY`` cycles and the correlator reset after ``CORR_RESET_DELAY`` cycles. All synchronous reset outputs are generated using ``xpm_cdc_async_rst`` for clean clock-domain crossing.
